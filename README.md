An end-to-end NLP project for customer support ticket classification and priority prediction.

## Features

- Ticket classification
- Priority prediction
- Transformer-based NLP models
- API deployment
- Monitoring pipeline
- Retraining workflow

## Tech Stack

- PyTorch

- Scikit-learn
